# 🍽️ Forkify Recipe App

A feature-rich recipe application built with **JavaScript, Sass, and the Forkify API**. This app allows users to **search for recipes**, **view detailed ingredient lists**, and **adjust serving sizes dynamically**. 🚀

## ✨ Features

- 🔍 **Search Recipes** – Fetch recipes using the Forkify API.
- 📋 **View Ingredients** – Get detailed ingredient lists for each recipe.
- 🔢 **Adjust Servings** – Dynamically update ingredient quantities.
- ❤️ **Save Favorites** – Bookmark and manage favorite recipes.
- 🔄 **Modern UI** – Styled with **Sass** for a sleek and responsive experience.
- ⚡ **Optimized Performance** – Uses **ES6 modules, async/await**, and **Parcel bundler**.

## 🛠️ Tech Stack

- **JavaScript (ES6+)**
- **Sass (SCSS)**
- **Forkify API**
- **Parcel (Module Bundler)**
